    Class User

    Representa un usuario dentro del dominio.

    Esta clase modela los datos y relaciones principales de un usuario, incluyendo sus datos personales, credenciales y relación con un rol.

    Example

    const user = new User(
      10,
      'user123',
      Password.create('hashed_password'),
      Email.create('johndoe@example.com'),
      'John',
      'Doe',
      undefined,
      DocType.create('DNI', 'Documento Nacional de Identidad', 8),
      '12345678',
      'Av. Los Pinos 123',
      2,
      true
    );
